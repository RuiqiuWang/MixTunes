## 修订的行为

- 歌单读取、结构验证或恢复失败时禁止自动保存。只有真正缺少主文件和备份时才创建新库。Android 不再因读取异常而自动把旧缓存写回原生存储。
- 每次覆盖主文件前保存上一份有效数据；恢复前保留原始文件。备份只在本机保存，不包含在歌单分享中。
- 当前来源歌单的拖拽排序更新待播顺序，保留当前媒体、进度、暂停意图和随机历史。修改其他歌单不影响当前播放；切换歌单后的旧拖拽请求被拒绝。
- 拖拽提示线与实际前后插入位置一致。批量选择使用集合核对归属，避免在大量选中项下反复扫描全表。
- 收起、展开和全屏切换复用同一视频；背景裁剪遮挡按最新状态恢复。销毁前取消回调、退出全屏并移除视图。
- 加载时调整进度仍生效；自然循环和手动重播回到片段开头。失败请求迟到时不能恢复播放。音量拖动期间保留用户值，结束才提交保存。

## 验证范围

自动检查包含共享单元测试、Android runtime、桌面与手机尺寸的浏览器 UI、Java 编译及原生辅助类测试。Electron 集成使用隔离歌单、本地合成媒体或受控平台响应；不使用个人账号与真实歌单。

Windows / Android 候选包需核对应用资源和签名。Android 真机登录、原站视频全屏／后台及付费内容的兼容性仍需设备验收；模拟原生桥、Java 编译和本地音频测试不代表这些场景已完成。
